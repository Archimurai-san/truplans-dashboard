TruPlans Dashboard v1.0
=======================

INSTALLATION
------------
1. Double-click "TruPlans Dashboard Setup 1.0.0.exe"
2. Windows may show a SmartScreen warning — click "More info" then "Run anyway"
3. The app installs automatically (no folder selection needed)
4. A desktop shortcut is created — double-click it to launch

FIRST LAUNCH
------------
- You will be asked "Who are you?" — select your name from the dropdown
- Your Tasks tab will default to showing your assigned work
- You can switch users at any time via the 👤 button in the top nav bar

REQUIREMENTS
------------
- Windows 10 or Windows 11 (64-bit)
- Internet connection required for AI features (contract analysis, PDF import)
- The backend server (server.js) must be running separately for AI features
  Start it with: node server.js  (requires Node.js installed)

FEATURES
--------
- Dashboard: KPI cards, revenue charts, SLA tracking
- Projects: full project table with workflow, payments, city/HOA tracking
- Tasks: real-time task list with due dates and completion checkboxes
- Gantt: 2026 project timeline
- Team: designer workload view
- Global search across all projects and workflow steps
- Email templates with one-click Gmail compose
- Weekly PDF report generator (printer icon in nav bar)
- Windows desktop notifications for SLA alerts and payment reminders

DATA STORAGE
------------
All project data, settings, and preferences are saved locally on this computer.
No data is sent to external servers except when using AI features (Claude API).
