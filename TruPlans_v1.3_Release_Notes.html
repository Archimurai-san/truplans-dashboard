What's New in v1.3

New Tab

🤖 AI Assistant

A new AI tab in the navigation bar. Type any question about zoning, workflow, or projects and get an instant answer. San Diego zoning (all 33 residential zones) is fully loaded into the knowledge base.

New Feature

🗺 City Resource Buttons

Open any project — if it's in San Diego, Irvine, Carlsbad, San Clemente, Mission Viejo, or Rancho Santa Margarita, two buttons appear in the header: Zoning Map and Municipal Code. One click opens the right city resource.

Improvement

📍 Address in Project Header

If a project has an address in its notes, it now shows automatically in the Project Detail header — no digging through notes needed.

Improvement

📅 Gantt Year Switcher

The Gantt tab now has ← 2025 · 2026 · 2027 → · TODAY buttons. Switch between years to see past or future project timelines. Works in both light and dark mode.

Improvement

✉️ Use Template from Inbox

When reading an email in the Inbox tab that matches a project, a green "✉ Use Template" button appears. Click it to open the email template modal pre-loaded with that project's data — without leaving the inbox.

Improvement

📋 Contracts Button

The Project Detail header now has a dedicated Contracts button alongside Delete, Workflow, Assign Team, and Close — for quicker access to contract management.

Fix

🔒 API Key Security

The Anthropic API key is now stored securely in Supabase and never in the source code. Contract Analyser is fully operational with the new key.

Fix

🔄 Auto-Updater Activated

Starting from v1.3.0, all future updates install automatically in the background. The team never needs to manually download or install an update again.

How to Use the AI Assistant

Step 1

Open the AI tab

Click AI in the top navigation bar.

Step 2

Select a project (optional)

Use the dropdown to attach a project — the AI will include that project's city, phase, and contract info as context.

Step 3

Ask your question

Type any question and press Enter. Use the quick prompts at the bottom for common questions.

Step 4

Get the zone first

For zoning questions, open the project → click 🗺 Zoning Map → click the parcel → note the zone code → come back and ask the AI about that zone.
